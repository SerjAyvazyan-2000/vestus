# Vestus — керамическая мастерская

Демонстрационный одностраничный сайт керамической мастерской и арт-пространства Vestus (Москва, Нагатинская ул., 3А).

- `index.html` — лендинг
- `privacy.html` — политика конфиденциальности и cookie
- `assets/` — изображения, стили, скрипты

Сайт разработан в студии [Сайтика](https://studio-psi-olive.vercel.app/).
